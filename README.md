# Модель искусственного интеллекта для обнаружения сердечных заболеваний с использованием алгоритмов машинного обучения

## Выходные данные

**Название:** An Artificial Intelligence Model for Heart Disease Detection Using Machine Learning Algorithms

**Авторы:** Victor Chang, Vallabhanent Rupa Bhavani, Ariel Qianwen Xu, MA Hossain

**Журнал:** Healthcare Analytics, Volume 2, 2022, Article 100016

**DOI:** https://doi.org/10.1016/j.health.2022.100016

---

## 1. Проблема и цель исследования

Сердечно-сосудистые заболевания (ССЗ) — одна из ведущих причин смерти как в развитых, так и в развивающихся странах. Ранняя диагностика значительно повышает шансы на успешное лечение, однако традиционные методы (инвазивная диагностика, ангиография) имеют существенные ограничения.

**Цель работы** — создать систему обнаружения сердечных заболеваний на основе машинного обучения с использованием языка Python, которая позволяет точно и эффективно предсказывать наличие болезни у пациента.

## 2. Используемые данные

Датасет содержит **14 признаков** пациентов:

| Признак | Описание |
|---|---|
| age | Возраст |
| sex | Пол (0 — женщина, 1 — мужчина) |
| cp | Тип боли в груди (0–3) |
| trestbps | Артериальное давление в покое |
| chol | Уровень холестерина (mg/dl) |
| fbs | Глюкоза натощак > 120 mg/dl |
| restecg | Результаты ЭКГ в покое (0, 1, 2) |
| thalach | Максимальная ЧСС |
| exang | Стенокардия при нагрузке |
| oldpeak | Депрессия ST-сегмента |
| slope | Наклон ST при нагрузке |
| ca | Количество крупных сосудов (0–3) |
| thal | Тип дефекта (3/6/7) |
| target | Наличие заболевания (1 — есть, 0 — нет) |

Источник данных: UCI Machine Learning Repository (304 записи, 14 атрибутов).

## 3. Методология

### Предобработка данных
- Загрузка данных из CSV-файла с помощью Pandas
- Кодирование категориальных переменных в dummy-переменные (`pd.get_dummies`)
- Масштабирование числовых признаков (`StandardScaler` для: age, trestbps, chol, thalach, oldpeak)
- Разделение на обучающую и тестовую выборки

### Анализ данных (EDA)
- Гистограммы распределений по каждому признаку
- Тепловая карта (Heatmap) корреляционной матрицы
- Столбчатые диаграммы по целевой переменной

### Ключевые корреляции из статьи
- **Положительная корреляция** с target: `cp` (боль в груди), `thalach` (макс. ЧСС), `slope`
- **Отрицательная корреляция** с target: `exang`, `oldpeak`, `ca`, `thal`

## 4. Сравнение алгоритмов машинного обучения

В работе рассматриваются и сравниваются следующие алгоритмы:

| Алгоритм | Точность (accuracy) |
|---|---|
| K-Nearest Neighbors (KNN) | ~87% |
| Random Forest Classifier | ~84% (тест: ~82%) |
| Support Vector Classifier (SVC) | ~83% |
| Decision Tree Classifier | ~79% |
| Logistic Regression | описана как базовый метод |

### Основной алгоритм — Random Forest
Авторы выбирают **Random Forest** как основной метод по следующим причинам:
- Высокая точность (~83% на train, ~82% на test)
- Устойчивость к переобучению (усредняет предсказания многих деревьев)
- Применим как для классификации, так и для регрессии
- Не требует сложной настройки гиперпараметров

**Принцип работы алгоритма:**
1. Случайная выборка K точек из обучающего набора
2. Построение N деревьев решений на подвыборках
3. Для каждой новой точки — голосование всех деревьев
4. Финальный класс — результат большинства голосов

### Метрики оценки
- Accuracy (точность)
- Confusion Matrix
- Precision, Recall, F1-score

---

## 5. Основные результаты

- Random Forest достиг точности **~83% на обучающей** и **~70–82% на тестовой** выборке
- Алгоритм KNN показал наивысшую точность в сравнении (87%), однако авторы отдают предпочтение Random Forest за его стабильность
- Корреляционный анализ подтвердил: наибольшее влияние на наличие заболевания оказывают тип боли в груди (`cp`), максимальная ЧСС (`thalach`) и депрессия ST (`oldpeak`)
